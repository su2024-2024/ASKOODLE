Demo and production are intentionally different

what runs today vs. what ships

The demo optimizes for zero or minimal provider cost. Production optimizes for predictable quality, text-bearing educational visuals, document grounding and measurable validation — with every AI model called by API, no self-hosted GPU inference to operate.

CURRENT DEMO

Free / low-cost provider chain

  • Flask + Jinja2 + SQLAlchemy application
  • DeepSeek → Gemini 1.5 Flash → Groq → local FLAN-T5 fallback for text
  • BAAI/bge-small-en-v1.5 + LlamaIndex hybrid vector/keyword retrieval
  • Cloudflare FLUX.1 Schnell → Pollinations → RunPod image fallback
  • S3 image cache, Razorpay checkout, AWS/Cloudflare delivery
  • Explicit unlimited teacher/student demo accounts for frictionless demonstrations

Purpose: product demonstration and workflow validation. These free-provider costs are not used in the production margin table.

APPROVED PRODUCTION

Governed education AI stack

  • Gemini Embedding 2 for OCR + production embeddings
  • OpenAI text-embedding-3-small API for embeddings fallback — cheapest option, no self-hosting
  • DeepSeek V4 Flash for user-facing answer generation and independent answer verification — cheapest judge API, no self-hosting
  • GPT Image 2 Low primary; Qwen-Image-2512 fallback via Replicate/WaveSpeed API — cheapest at $0.02/image, no self-hosting
  • On-device TTS, policy gates, audit and tenant isolation
  • Application tier hosted on AWS (EC2/RDS/S3/CloudFront) — see AWS Hosting Cost tab

Purpose: commercial delivery using the model and control layers shown in the Architecture tab. Launch stack is API-only for every AI model; self-hosted GPU inference is a later scale option, not a launch requirement.

Configuration issue to close before production: the demo provider chain still defaults to legacy aliases such as deepseek-chat and gemini-1.5-flash. The paid environment must set and test explicit production model identifiers rather than relying on demo defaults.

Defensible message

"Turn your own curriculum into grounded explanations, visual analogies, quizzes, activities and graded assessments." That bundle is more defensible than claiming only document Q&A or AI summaries.

Primary pressure

NotebookLM already offers generous free document chat and study artifacts. Askoodle must demonstrate better classroom workflow, consistent text inside visuals, rubric-based validation and India-specific usability.
