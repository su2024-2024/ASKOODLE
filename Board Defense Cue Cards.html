Slide 3 — USP & Hypotheses

~30 s

Our USP is trust: every answer is checked against the school's own textbook, with a citation, before a learner sees it.

Three hypotheses. H1 — correct: checked answers match teachers ≥95%. H2 — learns: test scores lift ≥15%. H3 — used: ≥60% learners use it weekly.

Pilot gates: H1 fails → teacher copilot. H2 fails → redesign. H3 fails → pause. How rules and AI work — covered in architecture slide.

Slide 4 — Portfolio Choice & Market

~50 s

Session 3: portfolio choice. Five product ideas in a value vs difficulty box.

Top-left: strategic bet — Verified Student Tutor, B2B subscription. Chose this — only it produces learner mastery, which is what schools pay for.

Top-right: quick win — Teacher Copilot. Did not drop it — our costed flip option. If tutor misses learning-gain target, we switch without starting over. Helps teachers plan lessons, generate stories and visuals for concepts by mastery level, create quizzes. Teachers can judge right/wrong — students cannot.

Bottom-left: rejected. Auto-grading — privacy + low willingness to pay.

Bottom-right: not pursued. Open-web helper competes with free ChatGPT.

Why B2B? Schools pay, supply approved curriculum, collect consent. Consumer app fights free chatbots. Competitive: ChatGPT fluent but unverified; BYJU's/Vedantu aligned but expensive. Wizz = verified AI + citations + school-friendly price.

Slide 5 — Critical Requirement (FR4)

~75 s

FR4: no AI answer reaches a learner unless every claim is verified. Good call = correct delivered or wrong caught. Bad call = wrong answer shown as verified — must prevent.

Example: "What is the area of a circle?" AI responds with pizza story — πr², radius 7, area 154 sq cm.

Four steps, each automatic:

1. Break — split into individual facts
2. Find — textbook line for each fact
3. Score — separate AI judge, 0 to 1, below 0.8 fails
4. Decide — all pass → deliver with citation; any fail → retry once; still failing → teacher expert 24h

Once approved, saved permanently — same question never needs a human twice.

Five metrics: correct ≥95% · bad calls <2% · κ ≥0.70 · escalation ≤2% → ≤0.7% · latency <4s

Bridge: "Before I move to discovery, let me show you the scoring model running live."

Slide 6 — Discovery & Delivery

~65 s

Three stages like a driving licence — learner's permit, supervised driving, full licence. Don't move to next until we pass a test set in advance.

Stage 1 — Discovery. Jan to March, one quarter. Two questions: does the verification checker work on real curriculum? Can we answer for under ₹1? Piloted in 2 schools. H1 or cost fail → stop. ₹0.86 Cr is the entire exposure — cheapest failure we could design.

Stage 2 — Pilot. April to July, 10 schools, aligned with academic year. Tests: ≥60% learners weekly; <15% corrections; sustained 4 weeks. <40% usage → pause. Measure against term tests — PT1, Term 1.

Stage 3 — Production. Aug 2027+. Score ≥15% above matched classes. ≤0.7% human escalation. Voice Hindi + English same verification.

Slide 7 — Architecture

~60 s

Three layers, each doing one job.

Foundation: governed knowledge and data — the CORE. Built before any school rollout. Only school-approved curriculum. Each school's data completely separate. Progress stored as learning codes, not names. Data stays in India.

User asks a question: API gateway → auth + rate limiting. Task router (Jev model) decides: deterministic or non-deterministic?

Deterministic (~80%): Rules engine. NLP text similarity on our own servers, not paid API. Similarity ≥85% → answer from DB — pre-verified, zero AI cost. NLP handles paraphrasing — "describe" = "explain".

Non-deterministic (~20%): AI path → hybrid retrieval → context builder (versioned prompts) → DeepSeek generates.

Verification gate (FR4): Jev classifies claims → match evidence → Qwen judge scores → policy gate: pass / retry / escalate → output guard adds Verified or Pending Review badge.

Central AI team: weekly tests, pinned model versions, changes on 1 school first, rollback <1h.

Q&A Quick Reference

How did you calculate ₹0.86 Cr?
Show Pilot Cost tab in HTML: engineering ₹54L, AI variable ₹10L, infra ₹10L, onboarding ₹8L, ops ₹4L.
Per-user cost breakdown?
Show Profit Margin tab: Gemini ₹16.38+₹8.19, DeepSeek ₹14, GPT Image ₹28.90, Qwen ₹2.16, Jev ₹0.12, infra ₹7.90-21. Total ₹77-91/user/month.
Why 80-20 split?
Most K-12 questions are variations of same concepts. NLP handles paraphrasing. Only truly new questions need AI generation.
Why not below Grade 5?
Difficult for younger students to use independently. Start with 6-12, expand later.
How do you measure 15% improvement?
Baseline test → one chapter with product (Section A) vs without (Section B) → endline test. Aligned with PT1/Term 1.
What about SME costs?
2 SMEs ~₹15-20K each = ₹30-40K/month. Adds ~₹10/student. In pilot cost, not per-user unit economics. If pushed: "noted, we will update."
Sovereign AI / multilingual?
Future plan — Bhashini/Sarvam, 10 Indian languages, multimedia. Infrastructure stays in India. Mention ONLY if asked.
If professor pushes back on anything?
